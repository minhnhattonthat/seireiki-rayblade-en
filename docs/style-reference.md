# Style reference - character voices and approved pairs

Evidence: first-person pronouns and sentence endings counted per speaker over the whole script
(`work/scratch/voices.py`), the DC project's character notes, and the pilot (scene 000-001, batch b009, inserted and
checked in-game 2026-11-03: `work/qa/pilot/`). Match these voices; a line any character could have said is a miss.
